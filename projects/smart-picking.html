— THE PROBLEM

Pickers were walking the warehouse, not picking it.

Pharmaceutical fulfillment carries constraints that ordinary e-commerce doesn't: temperature zones, expiry-date ordering (FEFO), controlled-substance handling, and split-batch traceability. Add a healthcare customer base where every minute of delay compounds — and the existing manual pick process became the bottleneck.

Pickers were spending most of their time walking between bins instead of actually picking. Orders were processed in arrival order, not in geometry order. There was no system view of which items could be batched, which paths overlapped, or which expiry windows were closing.

— MY ROLE

Define the problem so engineering can solve it cleanly.

Engineering didn't need an algorithm thrown at them — they needed a crisply scoped problem with the right inputs, outputs, and constraints. My job:

  • Map the as-is picking workflow with ops teams; quantify time spent walking vs. picking vs. scanning.
  • Define inputs: customer orders, warehouse layout, current stock levels, expiry/batch metadata.
  • Define output: a single optimized pick list — sequenced by product, location, and walking path.
  • Encode pharma constraints (FEFO, controlled-substance, temperature-zone batching) into the problem statement.
  • Co-design the solution with engineering — make trade-offs explicit, prioritize what ships first vs. later.
  • Validate against real picker workflows in UAT before rollout.

— THE ALGORITHM, AT A PRODUCT LEVEL

Three inputs, one output, many constraints.

Input · Orders

Customer order lines, SKU quantities, due times. Some are stat-rush, some can wait. Some are split across batches.

Input · Layout

Warehouse map: bins, aisles, temperature zones, walking distances. Static-ish, but periodically re-baselined.

Input · Stock

Real-time bin contents with batch numbers and expiry dates. FEFO drives which physical unit gets pulled.

Output · Pick path

An ordered list of bin visits. Each line: product, location, quantity, batch ID. Optimized for walking distance and constraint adherence.

— OUTCOMES

What changed for the pickers.

  • 70% picking efficiency improvement for pharmaceutical logistics clients.
  • Walking time collapsed — pickers cover fewer meters per order because adjacent items are batched and sequenced.
  • FEFO compliance moved from manual to systemic — expiry-aware sequencing is now a default, not a checklist item.
  • Operational confidence — ops teams trust the system enough to deprecate the manual pick-list workflow.
