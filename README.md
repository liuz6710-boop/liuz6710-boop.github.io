# liuxinyao.dev — personal site

Static portfolio site: hand-written HTML/CSS/JS, no build step.

- `index.html` — home (hero, work, about, contact)
- `projects/*.html` — case studies (CFS platform, smart picking, robotics dashboard, ESG simulation, RoleScout)
- `styles.css`, `script.js` — shared styling and scroll behaviour (the background video is scrubbed by scroll position, so it needs `preload="auto"`)
- `img/`, `video/` — assets

Deployed with GitHub Pages from the `main` branch.
